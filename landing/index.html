05 / FAQ

Common questions

Read the user guide
Do I need an account?+

No. Studio does not require an account or a Rebar subscription.

What is the difference between web and desktop?+

The desktop app exports PDFs directly. The web app uses the browser’s print dialog. Mixed portrait and landscape pages require the desktop app.

How do I back up my work?+

In Settings, choose “Back up now” to export a .rebbackup file. You can restore it on another device. Keep a backup before clearing browser data.

Do I need to know how to code?+

Filling documents does not require code. Creating or editing a template uses .reb source, which combines HTML with form fields. Sample templates and editor snippets are included.

Does Studio sync between devices?+

No. Transfer documents using .rebdoc files, or move the full workspace using a backup.
