FAQ

Questions fréquentes

Guide d’utilisation (anglais)
Faut-il un compte ?+

Non. Studio ne nécessite ni compte ni abonnement à Rebar.

Quelle différence entre le web et l’application de bureau ?+

L’application de bureau exporte directement les PDF. La version web utilise la boîte de dialogue d’impression du navigateur. Les documents combinant des pages portrait et paysage nécessitent l’application de bureau.

Comment sauvegarder mon travail ?+

Dans les paramètres, choisissez « Back up now » pour exporter un fichier .rebbackup. Vous pouvez le restaurer sur un autre appareil. Conservez une sauvegarde avant d’effacer les données du navigateur.

Faut-il savoir coder ?+

Remplir un document ne nécessite pas de code. Créer ou modifier un modèle utilise du code .reb, qui combine HTML et champs de formulaire. Des exemples de modèles et des extraits de code sont inclus.

Studio se synchronise-t-il entre appareils ?+

Non. Transférez vos documents avec des fichiers .rebdoc, ou déplacez tout l’espace de travail avec une sauvegarde.

Faut-il Rebar pour utiliser Studio ?+

Non. Studio fonctionne indépendamment et gratuitement. Rebar inclut les mêmes outils dans sa plateforme de gestion des opérations de construction.
